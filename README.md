# 👑 皇冠对决 · Crown Duel

**一款灵感来自《部落冲突：皇室战争》玩法的 HTML5 卡牌塔防对战游戏**
*单机 vs AI · 本地双人对战 · 纯 Canvas 渲染 · 零依赖*

🎮 [在线试玩（GitHub Pages）](https://pH2HP.github.io/crown-duel/)

</div>

## ✨ 特性

- ⚔️ 经典对战玩法：圣水经济、卡牌轮换、双路三塔、3 分钟限时对决
- 🃏 62 张原创卡牌：近战 / 远程 / 飞行 / 攻城单位 + 建筑 + 法术，牌库界面可滚动浏览
- 🎴 卡组系统：从 62 张卡中挑选 8 张出战，每场对局双方各带 8 张（AI 每局随机 8 张，双人模式双方各自选卡组）
- 🏰 拆塔扩张：摧毁敌方一座防御塔后，卡牌可部署到该塔所在边路的敌方半场
- 🧱 网格部署：战场划分为小方格，卡牌只能从格子开始放置；放置时显示淡色网格与占地预览，建筑有 1×1 / 2×2 两种占地
- 🎹 键盘对战（双人模式）：下方玩家用 1-4 选卡、WASD 移动光标、空格部署，上方玩家用鼠标，一个鼠标也能同屏对战
- 🙃 敌方视角翻转：双人模式中上方阵营的单位、建筑与卡牌上下翻转绘制，坐在对面看才是正的
- 🔊 环境音效：五大竞技场各有专属环境氛围音（草地鸟鸣 / 荒漠风沙 / 石地风声 / 圣殿钟声 / 暗黑低鸣），音量刻意保持很轻
- 🌉 地形规则：地面单位只能从桥过河，飞行单位可任意飞越河道
- 🐦 飞行单位：地面近战单位无法攻击空军（塔与远程单位可以）
- 🧱 建筑生命值上调：防御建筑与兵营更耐打，站场时间更长
- 🚶 运动模型优化：单位按移动方向转身、接近目标自然减速、同队单位互相避让不再重叠
- 🎨 画面细节：场地草丛小花、河面波光、桥面光影、塔身光晕与画面暗角
- 🏗️ 建筑体系：自动射击的防御建筑、持续出兵的兵营、产出圣水的圣水泵
- 🧊 状态与区域法术：冰冻、减速、毒药持续伤害、狂暴加速、雷电三连击、地震拆塔……
- 🗣️ 角色语音：每张卡牌部署时念出专属台词（不同角色不同音调语速，可随音效静音）
- 💾 进度自动保存：对局每 3 秒自动存档，中途退出下次可「继续上次对局」
- 📊 生涯战绩：总场次 / 胜 / 负 / 平 / 最高奖杯一目了然
- 📤 存档导出导入：一键把全部进度导出为 JSON 文件，换浏览器换设备都不丢
- 🏆 奖杯系统：胜利赢得奖杯与金币，失败扣减，战绩本地存档
- 👑 三皇冠机制：摧毁国王塔时，该方所有防御塔一并倒塌，胜方独享 3 皇冠
- 🎯 塔射程限制：双方塔的攻击范围严格小于到中分线的距离，不再隔河对射
- ⚔️ 11 档难度：简单 / 普通 / 标准 / 较难 / 困难 / 极难 / 专家 / 宗师 / 巅峰 / 地狱 / 无双，AI 强度与胜利奖励逐档提升
- 🎁 奖杯宝箱：首次达到 300 / 700 / 1200 / 1800 / 2400 / 3000 奖杯自动开启对应宝箱（青铜→巅峰）
- 🔓 卡牌解锁：卡牌按奖杯阶段解锁，更高竞技场解锁更强卡牌（未解锁卡在牌库与卡组界面显示 🔒 与所需奖杯）
- 🏟️ 5 大竞技场：积累奖杯解锁更高竞技场，每座竞技场拥有专属战场配色
- ⭐ 卡牌等级 1~9：金币升级，每级 +10% 血量与伤害（AI 等级随我方平均等级，保证公平）
- 👥 双人对战：同屏上下分阵营（上方红方 vs 下方蓝方），双圣水条双卡槽，支持多点触控
- 🩸 阵营识别：我方血条绿色 / 敌方红色，单位带阵营光圈，敌我一眼可辨
- 🤖 11 档 AI 难度：会防守、会反打、会用法术终结残血塔、会治疗残兵，难度越高 AI 反应越快、圣水越快、等级越高
- ⚡ 最后 60 秒双倍圣水，翻盘与保塔都更刺激
- 🖱️ 支持鼠标与触屏：拖拽或点选出牌，实时部署预览
- 🔊 WebAudio 合成音效，可一键静音
- 🚫 无任何外部依赖，打开 `index.html` 即可游玩

## 🎮 玩法

| 项目 | 说明 |
| --- | --- |
| 目标 | 3 分钟内率先摧毁敌方**国王塔**（或时间结束时摧毁塔数领先）；国王塔被摧毁时其所有防御塔一并倒塌，胜方获得 3 皇冠 |
| 圣水 | 随时间回复（每 2.8 秒 1 滴，上限 10），出牌消耗圣水；高难度 AI 的圣水回复更快 |
| 卡组 | 每场对局双方各携带 8 张卡（主菜单「🎴 选择卡组」编辑，顶部切换我方/对方；AI 每局随机 8 张，双人双方卡组独立） |
| 解锁 | 卡牌按奖杯解锁：0 奖杯解锁基础 23 张，300 / 700 / 1200 / 1800 奖杯逐步解锁更强卡牌；AI 卡组也只从已解锁卡中随机 |
| 部署 | 将卡牌拖拽/点选部署到**己方半场**，落点吸附到战场网格（拖动时显示淡色网格线，建筑按 1×1 / 2×2 占格高亮）；拆掉敌方一座塔后，可在该塔所在边路部署到敌方半场；法术可全场施放 |
| 过河 | 地面单位只能从**中央桥梁**过河（会自动绕行到桥头），飞行单位可任意飞越 |
| 塔 | 每方 3 座：2 座防御塔 + 1 座国王塔（敌方单位过河后国王塔激活；塔的攻击范围始终小于到中分线的距离） |
| 建筑 | 可部署防御/兵营/圣水泵建筑，会被敌方单位攻击与摧毁 |
| 结算 | 国王塔被摧毁立即获胜；时间结束按摧毁塔数 → 剩余塔血量判定 |
| 难度 | 主菜单 ◀ ▶ 循环选择 11 档难度：难度越高 AI 等级越高、反应越快、圣水越多，胜利奖杯 +50 ～ +150 逐档 +10 |
| 宝箱 | 奖杯首次达到 300（青铜）/ 700（白银）/ 1200（黄金）/ 1800（传奇）/ 2400（宗师）/ 3000（巅峰）时自动开启，奖励金币 |
| 奖杯 | 单人胜利 +50 起（每档难度 +10）、失败 −25、平局 +15；双人模式不结算奖杯 |
| 金币 | 单人模式每局结算获得，用于升级卡牌 |

## 🕹️ 操作

- **单人模式**：下方为你的阵营（蓝方），AI 占据上方；开战前在难度选择器用 ◀ ▶ 切换难度（也可点中间直接进下一档）
- **双人模式**：下方蓝方（玩家1）与上方红方（玩家2）各自拥有手牌与圣水，支持双指同时操作；只有一个鼠标时，下方玩家可用键盘：**1-4 选卡 · WASD 移动光标 · 空格部署**，上方玩家继续用鼠标
- 双人模式中上方阵营的单位、建筑与手牌上下翻转绘制，方便坐在屏幕对面的玩家观看
- **出牌**：按住卡牌拖到战场松开（或点选卡牌后点击战场）
- **取消**：拖出战场外松开即取消
- 部署预览：绿色 = 可部署，红色 = 不可部署
- **升级卡牌**：主菜单 →「🃏 卡牌升级」，消耗金币提升等级（62 张卡牌可上下滚动浏览）
- **选择卡组**：主菜单 →「🎴 选择卡组」，顶部切换我方/对方卡组，点击卡牌加入/移出，需选满 8 张后保存；每场对局双方各携带 8 张卡（AI 每局随机 8 张，双人模式双方卡组各自独立）
- **角色语音**：出牌时角色念出专属台词（中文语音合成），点右上角静音按钮可连同音效一起关闭
- **继续对局**：对局中途退出后，主菜单会出现「▶ 继续上次对局」按钮，点击即可从原进度继续
- **导出/导入存档**：主菜单底部「📤 导出存档」下载 `crown-duel-save.json`；在新浏览器/新设备点「📥 导入存档」选择该文件即可恢复全部进度

## 💾 存档与进度

所有进度保存在浏览器 localStorage 中，包含：

| 数据 | 说明 |
| --- | --- |
| 奖杯 / 金币 / 卡牌等级 | 每局结算与每次升级后立即保存 |
| 生涯战绩 | 总场次、胜 / 负 / 平、历史最高奖杯 |
| 进行中的对局 | 每 3 秒自动快照一次，关闭页面前也会保存；下次打开可继续 |

> ⚠️ 建议用 `http://localhost` 方式运行（见下）。直接双击 `index.html` 以 `file://` 打开时，浏览器会把不同路径视为不同站点，移动文件夹可能导致旧存档「丢失」——此时用「导出/导入存档」即可把数据带过去。

## 🚀 本地运行

无需构建，直接双击打开 `index.html`，或：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

## 🛠️ 技术

- 原生 JavaScript（ES6+）+ Canvas 2D，无第三方库
- Web Audio API 实时合成音效
- Web Speech API 语音合成（角色台词，不同角色不同音调语速）
- 固定逻辑分辨率 + 设备像素比缩放，自适应窗口
- 粒子特效、浮动伤害数字、屏幕震动
- Pointer Events 多点触控输入（双人模式）
- localStorage 本地存档 + 对局快照序列化/恢复 + JSON 文件导入导出
