# 👑 皇冠对决 · Crown Duel

**一款灵感来自《部落冲突：皇室战争》玩法的 HTML5 卡牌塔防对战游戏**
*单机 vs AI · 本地双人对战 · 纯 Canvas 渲染 · 零依赖*

🎮 [在线试玩（GitHub Pages）](https://pH2HP.github.io/crown-duel/)

</div>

## ✨ 特性

- ⚔️ 经典对战玩法：圣水经济、卡牌轮换、双路三塔、3 分钟限时对决
- 🃏 12 张原创卡牌：10 个兵种 + 3 种法术，各有定位（坦克 / 群伤 / 远程 / 突袭 / 治疗）
- 🏆 奖杯系统：胜利赢得奖杯与金币，失败扣减，战绩本地存档
- 🏟️ 5 大竞技场：积累奖杯解锁更高竞技场，每座竞技场拥有专属战场配色
- ⭐ 卡牌等级 1~9：金币升级，每级 +10% 血量与伤害（AI 等级随我方平均等级，保证公平）
- 👥 双人对战：同屏上下分阵营（上方红方 vs 下方蓝方），双圣水条双卡槽，支持多点触控
- 🩸 阵营识别：我方血条绿色 / 敌方红色，单位带阵营光圈，敌我一眼可辨
- 🤖 两档 AI 难度：会防守、会反打、会用法术终结残血塔、会治疗残兵
- ⚡ 最后 60 秒双倍圣水，翻盘与保塔都更刺激
- 🖱️ 支持鼠标与触屏：拖拽或点选出牌，实时部署预览
- 🔊 WebAudio 合成音效，可一键静音
- 🚫 无任何外部依赖，打开 `index.html` 即可游玩

## 🎮 玩法

| 项目 | 说明 |
| --- | --- |
| 目标 | 3 分钟内率先摧毁敌方**国王塔**（或时间结束时摧毁塔数领先） |
| 圣水 | 随时间回复（每 2.8 秒 1 滴，上限 10），出牌消耗圣水 |
| 部署 | 将卡牌拖拽/点选部署到**己方半场**，法术可全场施放 |
| 塔 | 每方 3 座：2 座防御塔 + 1 座国王塔（敌方单位过河后国王塔激活） |
| 结算 | 国王塔被摧毁立即获胜；时间结束按摧毁塔数 → 剩余塔血量判定 |
| 奖杯 | 单人胜利 +50（困难 +70）、失败 −25、平局 +15；双人模式不结算奖杯 |
| 金币 | 单人模式每局结算获得，用于升级卡牌 |

## 🕹️ 操作

- **单人模式**：下方为你的阵营（蓝方），AI 占据上方
- **双人模式**：下方蓝方（玩家1）与上方红方（玩家2）各自拥有手牌与圣水，支持双指同时操作
- **出牌**：按住卡牌拖到战场松开（或点选卡牌后点击战场）
- **取消**：拖出战场外松开即取消
- 部署预览：绿色 = 可部署，红色 = 不可部署
- **升级卡牌**：主菜单 →「🃏 卡牌升级」，消耗金币提升等级

## 🚀 本地运行

无需构建，直接双击打开 `index.html`，或：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

> 存档（奖杯 / 金币 / 卡牌等级）保存在浏览器 localStorage 中。

## 🛠️ 技术

- 原生 JavaScript（ES6+）+ Canvas 2D，无第三方库
- Web Audio API 实时合成音效
- 固定逻辑分辨率 + 设备像素比缩放，自适应窗口
- 粒子特效、浮动伤害数字、屏幕震动
- Pointer Events 多点触控输入（双人模式）
- localStorage 本地存档
